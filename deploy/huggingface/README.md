# Milaan: AI payment reconciliation

Reconciles orders, payment-gateway settlements and bank credits. Deterministic
code owns every rupee; a read-only AI agent investigates the evidence.

Everything in this demo runs offline, with no API key. The benchmark data is
synthetic: generated with planted problems and a known answer key.

Source code, tests and full documentation:
https://github.com/saitejacodes/milaaan
